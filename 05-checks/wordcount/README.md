# wordcount

Count words in text files. **The code is badly formatted and has a type error on purpose**, so that `uv format` and `uv check` have something to fix.

```bash
uv format --check
uv check
```

Used in [uv Guide (5)](https://hobbyworker.me/en/dev/2026-10-15-uv-guide-5-format-check-audit/).
